YAVI

YAVI (Yet Another Validation) is a lambda based, type safe validation library for Java and Kotlin. It validates an object against constraints that are declared in Java code, reports every violation in a structured form and, for the applicative API, creates a value only when all of its arguments are valid.

A validator is built once and reused; validators are immutable and thread safe. A constraint treats {@code null} as valid by default and skips its check, unless the constraint is explicitly created to reject null. Violations carry a message id and the arguments needed to format the default or a localized message.

Entry points

  • ValidatorBuilder builds a Validator for a target type from property constraints, nested validators and conditional or group based rules. This is the usual entry point when an existing object is validated.
  • Yavi and ArgumentsValidatorBuilder build validators for the arguments of a constructor or factory method. The result is produced only when every argument is valid; see am.ik.yavi.arguments.
  • ValidatorFactory creates validators with an application wide message configuration.

Example of a property validator: 

Validator<Person> validator = ValidatorBuilder.<Person>of()
    .constraint(Person::getName, "name", c -> c.notBlank().lessThanOrEqual(20))
    .constraint(Person::getAge, "age", c -> c.greaterThanOrEqual(0))
    .build();
ConstraintViolations violations = validator.validate(person);

Example of an arguments validator that creates a value only from valid arguments: 

Arguments2Validator<String, Integer, Person> validator = Yavi.arguments()
    ._string("name", c -> c.notBlank())
    ._integer("age", c -> c.greaterThanOrEqual(0))
    .apply(Person::new);
Validated<Person> validated = validator.validate("Alice", 20);

Package map

  • am.ik.yavi.builder: builders for property and arguments validators.
  • am.ik.yavi.arguments: immutable argument containers and validators that produce a validated result.
  • am.ik.yavi.validator: the Yavi entry point for argument validation.
  • am.ik.yavi.core: the validation engine, violations, groups, conditions and applicative value validators.
  • am.ik.yavi.constraint: constraints for numeric, temporal, character sequence, object and container values, with subpackages for arrays, character sequence details, IP addresses and password policies.
  • am.ik.yavi.message: message formatting and localized message lookup.
  • am.ik.yavi.meta and am.ik.yavi.processor: compile time annotations and the annotation processor that generates type safe metadata.
  • am.ik.yavi.factory: factories that share a validation configuration.
  • am.ik.yavi.fn: functional primitives for applicative validation.
